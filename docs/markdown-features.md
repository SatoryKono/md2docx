# Возможности Markdown → DOCX

## Заголовки

- `# ВВЕДЕНИЕ` — structural (ПРОПИСНЫЕ, с новой страницы), если keyword  
- `# 1 Раздел` — Heading 1 (разрыв страницы)  
- `##` / `###` — Heading 2 / 3 (пустая строка перед)  

## Индексы

| Синтаксис | Результат |
|-----------|-----------|
| `H_2O` | подстрочная 2 |
| `x^2` | надстрочная 2 |
| `x_{i+1}` | подстрочный блок |
| `a^{n}` | надстрочный блок |
| `\_` `\^` | литералы |

## Списки

- Ненумерованный: маркер **—** (Em Dash) + **табуляция** (не пробел), стиль `GostListDash`  
- Нумерованный: `1) текст` в тексте, без Word auto-bullet  

## Таблицы / рисунки

- Подпись таблицы: `Таблица: …` — пустая строка перед  
- После таблицы — пустая строка  
- Подпись рисунка: пустая строка до и после  
- В ячейке: 3 pt top/bottom; multi-para — 3 pt только у первого сверху и последнего снизу  
- `<br>` в ячейке → новый абзац  

## Формулы

`$$E = mc^2$$` — с индексами, номер справа.
